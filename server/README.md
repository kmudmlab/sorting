# 제출 서버 운영 안내

과제 제출 시 Google Apps Script가 학생 함수를 다시 채점하고 Google Form과 연결된 비공개 시트에 기록합니다. 브라우저 점수는 공식 점수 계산에 사용하지 않습니다.

서버 소스와 테스트 파일은 공개 저장소에 포함하지 않습니다. 비공개 Apps Script 프로젝트와 교수님의 로컬 작업 폴더에 보관합니다.

- 연습 채점은 브라우저에서, 최종 제출 채점은 서버에서 실행합니다.
- 고정 코드와 테스트 입력은 서버가 관리합니다.
- 학생 코드에는 연산 수·실행 시간·메모리 사용을 제한합니다.
- Form 응답자 권한은 소유자만 허용하고, 응답받기는 켜 두어 서버가 기록할 수 있도록 합니다.
- 응답 수정과 결과 요약 공개는 허용하지 않습니다.
- 학번과 이름은 학생이 입력합니다. 학생 Google 계정 인증 기능은 포함하지 않습니다.
- 제출 완료와 서버 점수는 저장 응답을 확인한 뒤 표시합니다. 수정 후 재제출할 수 있습니다.

검증용 TEST2026 응답은 실제 학생 성적과 구분해 관리하세요.
