# SORT / LAB

Python 정렬 코드를 입력하고 배열의 변화와 비교 연산을 애니메이션으로 살펴보는 정적 웹 서비스입니다.

**접속:** https://dm.kookmin.ac.kr/sorting/

https://kmudmlab.github.io/sorting/ 주소로 접속해도 같은 사이트로 이동합니다.

## 사용 방법

1. 버블·선택·삽입·퀵·병합 정렬 예제를 선택하거나 `sort(arr)` 함수를 작성합니다.
2. 숫자 배열을 입력하고 **실행 & 재생**을 누릅니다.
3. 이전·다음 단계, 슬라이더, **다음 비교** 버튼으로 실행 과정을 살펴봅니다.

비교 단계에서는 왼쪽 피연산자 A와 오른쪽 피연산자 B, 실제 값과 비교 결과를 표시합니다. 배열 원소를 비교하면 해당 위치를 강조하고, 별도 변수나 보조 배열과의 비교도 구분합니다.

## 실행 및 배포

- `index.html` 하나에 화면, 실행기, 예제 코드가 들어 있습니다. 브라우저에서 파일을 직접 열어도 실행할 수 있습니다.
- Python 실행기는 Pyodide 0.27.7을 사용합니다. 최초 실행 시 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 사용자 코드는 브라우저의 Web Worker 안에서 실행됩니다.
- 입력은 −9999부터 9999 사이 숫자를 최대 60개 지원합니다. 기록은 최대 12,000단계이며 실행 제한 시간이 있습니다.
- GitHub Pages는 `main` 브랜치의 루트(`/`)에서 배포합니다. `index.html`을 수정해 올리면 사이트에 반영됩니다.

`sorted()`와 `list.sort()` 내부의 개별 연산은 시각화하지 않습니다.
